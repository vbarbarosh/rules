# demos

Small runnable examples of the naming families, each in a file of its own.

- [item_from.js](item_from.js) — `*_from_*`: a domain object built from its raw form
- [item_to.js](item_to.js) — `*_to_*`: a value converted from one representation to another
- [items_by.js](items_by.js) — `*_by_*` indexes by a unique key; `*_grouped_by_*` partitions into buckets
