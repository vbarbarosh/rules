# APIs

How an API is drawn, so a reader takes in what each request does at a
glance: in two forms. The compact form shows a whole resource, every request
a row; the expanded form takes one request apart, every part named. Drawn
the way the [diagrams](https://vbarbarosh.github.io/rules/docs/diagrams.html)
are: the same colours, words as big as the text around them.

- [compact.md](compact.md) — the compact form: one resource, every request a row, what it sends, what it gets back, what the server keeps after it and whether sending it twice changes more; the methods coloured by what they do to the data
- [expanded.md](expanded.md) — the expanded form: one request and its answer taken apart, the method and address, the headers, the body and the status, each named on the side with what it is for
