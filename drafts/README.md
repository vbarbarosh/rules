# drafts

The rule documents, one per subject, with what shows them. The rules in
them are listed, a row each, in [the rule index](../docs/rules.html), every
row linking back to its document. The documents are listed by topic in
[the rulebook](../docs/README.md); this page keeps no second list of them, so the
two can never disagree.

Beside the documents:

- `*.html` — a live demo or a cheatsheet of the document of the same name
  (`scroll-anchoring.html` for [scroll_anchoring.md](scroll_anchoring.md))
- `*.png`, `*.gif` — its pictures, each light with its `-dark` twin
- [scroll-anchoring.test.js](scroll-anchoring.test.js) — the browser test of the scroll-anchoring demo
- [WRITING.md](WRITING.md) — how a document is written: the author's notes and the approved rules first, the explanation regenerated from them
