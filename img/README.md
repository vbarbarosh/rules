page or glossary; its pictures are reached from that page, so the folders
have no index of their own.

- [theme-sun.svg](theme-sun.svg), [theme-moon.svg](theme-moon.svg) — the icons of the theme switch ([license](theme-icons.LICENSE))
- [rules/](rules/) — the rules page, and the Motion glossary
- [guides/](guides/) — the instructions for agents
- [diagrams/](diagrams/) — the diagrams page
- [apis/](apis/) — the APIs page
- [agents/](agents/) — the Agents glossary
- [architecture/](architecture/) — the Architecture glossary
- [doc/](doc/) — the Documents glossary
