# Standard names (NAMES)

Plain public names, used in place of private ones: the same word for the same
thing in every project, so a reader outside knows at once what it is. Several
of one kind are numbered from 1: `laptop1`, `laptop2`, `vps1`, `vps2`.

**Machines** (MACH)

- laptop – a portable computer the author works on
- desktop – a computer at a desk, not carried
- phone – a mobile phone
- tablet – a tablet
- server – a machine that serves others, at home or in an office
- vps1, vps2 – a rented virtual server, numbered in the order they appear
- router – the network's router
- nas – a network storage box
- box – a container or virtual machine an agent or a service runs in

**Placeholders** (PLACE)

- example.com – a domain; subdomains under it (`api.example.com`)
- user@example.com – an e-mail address
- user – a user name; `/home/user` a home folder
- 192.0.2.x – an IPv4 address (RFC 5737, reserved for documentation)
