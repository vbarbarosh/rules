## Questions for the author, with a recommendation each

- **Q1 NAME-02 and the ESLint rule files.** Each `src/rules/x.js` declares `function x(context)`, a noun. Recommend: `x_create(context)`, then FILE-20's declared export follows.
- **Q2 FILE-20 and `src/config.js`.** Its export is `rules_config`. Recommend: keep the file and the published `./config` path, name the function `rules_config_make` and the file to match, keeping `./config` as the package export.
- **Q3 NAME-17 and verb-first names** (`check_gap`, `open_page`, `copy_markdown`, generic `check`, `report`). The audit read NAME-17 as domain-first everywhere; the author has preferred verb-first for steps and formatters (`build_rules_html`). Recommend: verb-first stays for steps, generic one-word names get their domain (`check` → `name_check`).
- **Q4 The release layout** (REL, PROJ-04). The package ships through npx from git; the built pages are what GitHub Pages serves. Recommend: REL applies only when there is something to ship besides the pages; keep docs/*.html committed as the published site and say so in an exception.
- **Q5 Event handler families**: are `input_q`, `keydown_document`, `scroll_window` the same family as `click_*`? Recommend: yes, `<event>_<target>` is one family.
- **Q6 FMT-31 and `out += x`**. Recommend: an accumulator is not a join; leave it.
- **Q7 UI-09 against UI-05**: the docked theme switch opens and moves the bar's count 66 px left. Recommend: reserve the switch's width, so nothing moves.
- **Q8 Space on the docs pages** goes into the filter instead of scrolling. Recommend: Space scrolls while the filter is empty.
- **Q9 A check for FMT-27 and FMT-31 in the preset**, so consumers' code is checked too. Recommend: yes; both are mechanical.

The remaining questions the readers raised (theme IIFE before paint, `is_new` as data, CSS-07 and grid rows, CSS-09 in plain CSS, LOG scope for console output, FMT-11 for arrays, FMT-28 in bash, the review note's ids, PROJ-13/14 for this repo) are minor; each is decided by Q1-Q9's answers or can wait.
