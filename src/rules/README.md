# src/rules

One file per lint rule of the preset; what each enforces is in the table of
[LINTING.md](../../LINTING.md).

- [block_layout.js](block_layout.js) — `block-layout`: where braces and bodies go
- [error_name.js](error_name.js) — `error-name`: `e` in arrows, `error` in functions and catches
- [imports_sorted.js](imports_sorted.js) — `imports-sorted`: the import block, sorted, in up to three blocks
- [operator_spacing.js](operator_spacing.js) — `operator-spacing`: tight `*`, `/`, `**`; spaces around the rest
- [return_out.js](return_out.js) — `return-out`: return the expression; `out` only when built up
- [tiny_arrows.js](tiny_arrows.js) — `tiny-arrows`: when an arrow is one line, and its parameter `v`
- [vue_class_order.js](vue_class_order.js) — `vue-class-order`: the order of classes in a template
- [vue_hashtag_syntax.js](vue_hashtag_syntax.js) — `vue-hashtag-syntax`: the forms the hashtag loader reads
- [vue_layout_classes.js](vue_layout_classes.js) — `vue-layout-classes`: the layout group, `gap` last
- [vue_local_class_style.js](vue_local_class_style.js) — `vue-local-class-style`: every local `#-*` class has its style
- [vue_style_conventions.js](vue_style_conventions.js) — `vue-style-conventions`: `@import` and `@include` first
