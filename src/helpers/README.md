# src/helpers

What the lint rules share, one function per file.

- [category_of_class.js](category_of_class.js) — the family of a utility class (layout, spacing, sizing…), from smcss
- [class_attribute_name_of.js](class_attribute_name_of.js) — the name of a template attribute that holds classes
- [classes_from_attribute.js](classes_from_attribute.js) — the classes of a template attribute, each with its place
- [is_error_callback.js](is_error_callback.js) — whether a function is an error callback
- [sass_keyframes_normalize.js](sass_keyframes_normalize.js) — keyframe percentages made readable to the Sass parser
- [vue_styles_parse.js](vue_styles_parse.js) — the `<style>` blocks of a Vue component, parsed
